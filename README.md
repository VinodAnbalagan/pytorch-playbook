# PyTorch Playbook

A collection of Jupyter notebooks for learning and exploring deep learning concepts with PyTorch. This playbook covers everything from fundamental PyTorch basics to advanced neural network architectures including transformers, autoencoders, and energy-based models with toy models and simple examples.

## 📚 Notebook Guide

### 1. **PyTorch Basics** 
Introduction to PyTorch fundamentals, including tensors, gradients, and basic operations to get started with the framework.

### 2. **Activation Functions** 
Comprehensive exploration of various activation functions (ReLU, Sigmoid, Tanh, etc.) and their applications in neural networks.

### 3. **Optimization and Initialization** 
Deep dive into optimization algorithms (SGD, Adam, etc.) and weight initialization strategies for training neural networks effectively.

### 4. **CNN Foundations**
Introduction to Convolutional Neural Networks, including convolution operations, pooling, and building basic CNN architectures.

### 5. **Inception, ResNet, and DenseNet** 
Exploration of modern CNN architectures including Inception, Residual Networks, and Dense Networks.

### 6. **Attention and Transformer Foundations**
Introduction to attention mechanisms and the foundational concepts of Transformer architectures.

### 7. **Transformer Multi-Head Attention** 
Detailed study of multi-head attention mechanisms and their implementation in transformers.

### 8. **Energy Model Foundations** 
Introduction to energy-based models, including concepts and implementation details.

### 9. **Autoencoders with MNIST** 
Hands-on tutorial on building and training autoencoders using the MNIST dataset.

### 10. **GRU Foundations**
Exploration of Gated Recurrent Units (GRUs), a variant of recurrent neural networks for sequence modeling.

### 11. **Latent Dynamics and Predictive Sequence Models** 
Advanced topic on modeling latent dynamics and building predictive models for sequential data.

## 🚀 Getting Started

### Prerequisites
- Python 3.7+
- PyTorch
- Jupyter Notebook
- NumPy
- Matplotlib (for visualizations)

### Installation

1. Clone this repository:
```bash
git clone https://github.com/VinodAnbalagan/pytorch-playbook.git
cd pytorch-playbook
```

2. Install required dependencies:
```bash
pip install torch torchvision pytorch-lightning jupyter numpy matplotlib
```

3. Launch Jupyter Notebook:
```bash
jupyter notebook
```

4. Open any notebook and start learning!


## 🎯 Topics Covered

- **Core Concepts**: Tensors, gradients, automatic differentiation
- **Optimization**: Various optimizers and their implementations
- **Architectures**: CNNs, ResNets, Transformers, RNNs, Autoencoders
- **Attention Mechanisms**: Single and multi-head attention
- **Recurrent Networks**: GRUs for sequence modeling
- **Generative Models**: Energy-based models and autoencoders
- **Advanced Topics**: Latent dynamics and predictive sequence models
